# Instana Examples
Examples that can help you succeed with Instana

- `agent_real_airgap` directory: Scripts to help you with a real airgap environment on Openshift, assuming you don't have access even to a Bastion host.
- `instana-scripts` directory: Scripts for crazy use cases that interact with the Instana API mostly.
- `agent_daemonset and agent_kubernetes` directories: Examples on how to tweak the agent, specially with additional backends.
- `mule-app-hello-world-otel`directory: An application that can be installed on MuleSoft Anypoint and teaches you how to monitor it using Otel and Instana.
